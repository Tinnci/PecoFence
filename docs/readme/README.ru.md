## Всему своё место

Проекты, скриншоты, статьи «на потом» — держите их в отдельных группах, расставленных так,
как вам удобно работать. PecoFence добавляет ровно столько порядка, чтобы рабочим столом
снова было приятно пользоваться.

| **Группируйте работу** | **Держите папки рядом** | **Освобождайте место** |
| :--- | :--- | :--- |
| Заведите по области на каждый проект. Перетаскивайте, растягивайте — она сама встанет на место. | Поставьте живую папку прямо на рабочий стол. Заглядывайте в подпапки и следите за изменениями в реальном времени. | Двойной щелчок по рабочему столу скрывает все области. Ещё один двойной щелчок возвращает их. |

## PecoFence в действии

### Одно окно. Несколько рабочих пространств.

Держите связанные области вместе как вкладки. Переключайтесь с Work на Art одним щелчком,
а когда нужно больше места — вытащите вкладку в отдельную область.

![Переключение между Work и Art, затем вкладка отделяется в собственную область.](../assets/tabs.gif)

### Рабочий стол — в одном сочетании клавиш.

Нажмите **Ctrl + Alt + Пробел**, и области появятся поверх текущего приложения.
Возьмите нужное и нажмите **Esc**, чтобы вернуться.

![Функция «Поверх окон» показывает области над приложением; Esc возвращает к приложению.](../assets/peek.gif)

<sub>Записано в PecoFence на демонстрационных файлах с темой Fluent. GIF воспроизводятся по кругу.</sub>

## Мелочи, из которых складывается удобство

| Возможность | Что это даёт |
| :--- | :--- |
| **Меньше ручной сортировки** | Правила по типу файла, расширению, имени, маске, цели ярлыка, времени и размеру. Новые файлы сами находят свою область. |
| **Стекло под ваш рабочий стол** | Темы Fluent и Liquid Glass, светлый и тёмный режимы, свой цвет для каждой области, непрозрачность и тонирование значков. |
| **Привычная работа с файлами** | Контекстные меню Проводника, перетаскивание, копирование и вставка, множественный выбор, эскизы и виды «Значки», «Список» и «Таблица». |
| **Место, когда оно нужно** | Сверните область до заголовка — она развернётся при наведении. Закрепите расположение, которое вам нравится. |
| **Путь назад** | Снимки расположения, ежедневные резервные копии, импорт и экспорт конфигурации, обмен областями между мониторами. |
| **Нативные настройки** | Настройки уже используют нативные элементы WinUI 3 на Reactor: реализованы пять страниц задач и тринадцать форм условий правил. Headless-тесты и синтетический тур WinUI, включая закрытие и повторное открытие, прошли; это не доказывает полного соответствия функциям или готовности к выпуску. Выбранная поставка включает автономный Windows App SDK Runtime 2.5.1 без отдельной установки и исключает WebView2 (проверка итогового пакета ещё не выполнена). Runtime увеличивает размер пакета и расход ресурсов. Улучшение размера или запуска не заявляется. |

Автоматические правила не трогают сами файлы — те остаются на прежнем месте.
Перемещения, которые начинаете вы, работают так же, как в Проводнике.

## Скачать PecoFence

Это независимо поддерживаемая редакция в [Tinnci/PecoFence](https://github.com/Tinnci/PecoFence).
Её каналы Microsoft Store и winget не настроены; опубликованных релизов пока нет.
Проверьте [Releases](https://github.com/Tinnci/PecoFence/releases) или
[артефакты CI](https://github.com/Tinnci/PecoFence/actions) этого репозитория на наличие сборок
либо соберите приложение из исходного кода по инструкции ниже.

1. Когда портативная сборка станет доступна, скачайте `pecofence-<версия>-x64.zip` из Releases или артефактов CI этого репозитория.
2. Распакуйте **весь ZIP-архив** в папку и запустите `pecofence.exe`.
3. Начинайте наводить порядок. Настройки и выход — по правому щелчку на значке в трее.

**Windows 11 x64 · Портативный ZIP · Без учётной записи · Лицензия Apache 2.0**

При первом запуске появятся области «Программы», «Папки», «Файлы и документы» и «Рабочий стол»
на выбранном языке. При выходе значки рабочего стола Windows возвращаются на место.

- Рассчитано на Windows 11 22H2 и новее. Основное тестирование проходило на 25H2;
  полная проверка на более старых версиях и с несколькими мониторами ещё продолжается.
- В настройках уже есть пять нативных страниц задач на Reactor/WinUI 3. Headless-тесты и синтетический
  тур WinUI, включая закрытие и повторное открытие, прошли; это не доказывает полного соответствия
  функциям или готовности к выпуску. Клавиатура, UI Automation/экранный диктор Narrator, высокая
  контрастность, масштаб текста, все десять языков при DPI 100%/150%/200% и чистая система обязательны
  для приёмки. Пакет, imports и процессы ещё нужно проверить на наличие автономного Windows App SDK
  Runtime и отсутствие компонентов WebView2. Full Windows CI ограничивает EXE до 6,5 МиБ
  (6 815 744 байт); окончательное измерение выпуска ожидается. Улучшение запуска или памяти не заявляется.
- Держите `pecofence-watchdog.exe` рядом с приложением для восстановления значков рабочего стола.
- Конфигурация хранится в `%APPDATA%\PecoFence\workspace.v2.json`. Запустите с параметром
  `--portable`, чтобы хранить её в папке `config` рядом с исполняемым файлом.
- Новый формат не импортирует и не преобразует старые конфигурации.
  Существующие файлы сохраняются; создайте рабочее пространство или импортируйте документ поддерживаемого формата.

<details>
<summary><strong>Сборка из исходного кода</strong></summary>

Установите Rust stable и Visual Studio Build Tools с рабочей нагрузкой C++ и Windows SDK.
Windows SDK — инструмент разработки, а не включённый в пакет Windows App SDK Runtime.
Публичная сборка использует только этот репозиторий и публичные реестры, включая
`crates/spm-contracts` (0.1.0); приватный токен и копия SPM не нужны.
Необязательный backend `Tinnci/spm` остаётся приватным и нужен только для живых
данных SPM, но не для компиляции или использования обычных групп рабочего стола.
Он не поставляется с PecoFence. См. [границу SPM](../SPM_BOUNDARY.md).

```powershell
cargo build --locked --release
```

Собрать портативный ZIP для распространения:

```powershell
./scripts/make-portable.ps1
```

Рабочее пространство разделено на `crates/` — приложение на Rust, `locales/` — переводы и
`scripts/` — скрипты проверки и упаковки. Выбранное направление настроек — нативный WinUI 3
на Reactor, а не веб-интерфейс.
Необязательный видеопроект в `extras/` от сборки приложения не зависит.

</details>
