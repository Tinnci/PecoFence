# 图表组件（Mermaid）

provider 为 `pecofence.diagram`，配置版本 1，格式为 `{ "source": "..." }`，正文最多 16384 个 UTF-16 单位。托盘与栅栏右键的“新建小组件 › 图表”创建 560×400 DIP 的组件，并立即打开多行编辑框，预填一个可修改的示例。

## 原生实现

参考 [Pele](https://github.com/obsidianmd/pele)（MIT）的思路：Mermaid 文本直接绘制为主题化矢量图。PecoFence 不嵌入 JavaScript 引擎，也不依赖 Node.js、浏览器或 SVG 渲染器，不复制 Pele 代码。`crates/plugin-widgets/src/mermaid.rs` 自行解析 Mermaid 子集并布局，`diagram.rs` 把结果映射为场景节点：节点为圆角矩形和文字，连线、箭头和菱形用场景节点的 `path` 折线绘制。因此图表随 DPI 保持清晰，使用暖纸色方案，节点文字可被 UIA 读取。

评估过 `mermaid-rs-renderer`（MIT，约 2.2 万行，依赖 regex、json5，并通过 fontdb 扫描系统字体测量文字）和 `merman`。为控制 6.5 MiB EXE 上限和启动开销，未引入。

## 支持范围

- `flowchart` / `graph`：方向 LR、RL、TB/TD、BT；节点形状 `[ ]`、`( )`、`([ ])`、`(( ))`、`{ }`（`[[ ]]`、`[( )]`、`{{ }}`、`> ]` 按近似形状绘制）；连线 `-->`、`---`、`-.->`、`==>`、`--x`/`--o`（按箭头绘制）、`<-->`；标签 `-->|文字|` 和 `-- 文字 -->`；`A & B --> C`；链式 `A --> B --> C`；`;` 分隔；`%%` 注释；front matter `title:`。`style`、`classDef`、`class`、`linkStyle`、`click`、`subgraph`/`end` 行会被忽略（子图不绘制边框）。
- `gantt`：`title`、`dateFormat YYYY-MM-DD`、`section`、任务 `名称 : [done|active|crit|milestone,] [id,] [开始,] 结束`；开始可为日期或 `after id…`，结束可为日期或 `Nd`/`Nw`。`axisFormat`、`excludes` 等行被忽略。
- 其他图表类型显示“暂不支持”。上限：200 个节点、400 条连线、120 个任务。

## 布局与呈现

流程图采用分层布局：最长路径分层（DFS 去环），六轮重心排序，各层沿公共轴居中，使并行分支对称；连线为正交折线，在层间空隙拐弯，回边从图下方的通道绕行。图按舞台大小缩放（不放大，最小 40%，再大则裁剪）。甘特图按任务行绘制条形，跨度不超过 12 周时按 ISO 周显示刻度，否则按月；“今天”以赤陶色竖线标出；关键任务为赤陶色，已完成为浅色，进行中为强调浅底，里程碑为菱形。

源码有误时页眉以警示色提示，舞台保留上次成功的图（淡化显示），底部横幅给出行号、原因和该行内容（UIA 角色为 alert）。整个舞台点击即编辑源码；支持撤销上一步。修改后图表淡入（250 ms，关闭“动画效果”时不播放）。高度低于 120 DIP 时显示单行胶囊摘要。

## 验证与限制

`cargo test -p pecofence-plugin-widgets` 覆盖解析（形状、链、分组、标签、错误行号、甘特依赖）、布局（并行分支对称、环与 TD 有限）、场景（节点在舞台内、箭头数量、直线与今天线确实绘制、错误横幅、空白与胶囊状态）。尚未在 Windows 设备上做视觉、IME、屏幕阅读器验收；文字宽度为估算值，长标签会被裁剪；虚线连线以浅色细线表示。
