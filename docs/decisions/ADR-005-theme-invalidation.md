# ADR-005：主题变化的失效规则

## 状态

Accepted。维护者 2026-09-23 采纳 Astra 第 5 轮推荐。

## 背景

颜色、字体、缩放、DPI 和图形设备变化影响不同层级的资源。当前 plugin-spm 的 `ThemeChanged` 分支按“颜色变、几何不变”处理；扩展字体或 text scale 时必须修改这一前提。

## 决策

- 普通颜色或 accent 变化：重绘。
- 字体家族、weight 或 text scale 变化：重新测量布局并更新命中区域。
- DPI 变化：按窗口更新尺寸、布局与资源。
- 图形设备失效：以独立 device epoch 重建设备相关资源。
- 高对比模式使用独立语义色，不沿用普通 accent；text scale 与 DPI 是不同变量。

## 否决的替代方案及理由

- 把所有变化塞入单一 epoch 并全量重建：混淆不同失效范围，造成不必要的资源重建，也难以单独验证几何和设备恢复。

## 影响范围

主题状态与通知、plugin-spm 的 `ThemeChanged` 处理、文本测量、命中区域、各窗口 DPI 处理和图形设备资源生命周期。

## 验收用例

覆盖文字缩放 100/150/200、两种高对比主题、字体切换、跨 DPI 和设备资源重建；逐项检查文字、焦点与点击区域，以及资源恢复，不能只凭截图颜色判定通过。

## 重开条件

无。
