## 冲突区域

- **插件内核与窗口渲染**：本仓已加入 `plugin-api`、`plugin-kernel`、`plugin-spm`，并重构 fence window 的预备帧和画布。`6bd8b81` 虽只改现有 `render` 文件及设置 UI，但圆角同时进入主题、合成裁剪、阴影、标题栏、插件可见的主题快照和几何失效链路。不能仅挑 `Theme::corner_radius` 常量移植；应验证各材质与 SPM 面板的视觉及命中区域。`da3e14c` 的托盘绘制与本仓 `visuals.rs` 的主题刷新同处一文件，也需核对图标在主题切换后的行为。
- **Theme 链路**：本仓 `ADR-005-theme-invalidation.md` 明确当前插件侧 `ThemeChanged` 主要按颜色变化处理。`6bd8b81` 修改的是几何；若吸收，应把快照、布局/测量、缓存失效、DPI 和绘制资源一并审查，再更新对应测试。
- **CI 与发布工程**：`e47f25d` 把 tag push 直接变成公开 Release；本仓当前仍用草稿发布，并对私有 `spm-contracts` 依赖增加了 CI 认证步骤。`6ce30d7` 的 Windows SDK `rc.exe` 构建脚本还会影响 WSL 交叉构建与 Windows CI：找不到工具时它会跳过资源，因此可能出现无图标的构建产物。版本提交 `fe5aa79`、`1cbd41e` 及 `08c8b80` 的下载/商店文案均不能直接代表本仓发布状态。
