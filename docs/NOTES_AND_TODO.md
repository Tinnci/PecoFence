# 便笺与待办的统一组件体验

本轮基于现有原生组件实现，参考 Microsoft Sticky Notes 的快速记录方式：
https://support.microsoft.com/en-us/windows/apps/stickynotes/create-a-sticky-note

## 创建与呈现

托盘和面板右键的“新建小组件”复用同一个菜单：便笺、待办清单、图表、数字时钟、日历（图表见 [图表组件](DIAGRAM_WIDGET.md)）。
MSIX 的 Windows Explorer 文件夹背景菜单扩展并列提供“新建便笺”和“新建待办清单”；普通 ZIP 安装不自动注册该扩展。新增 Shell action 使用 ID 4，保留已有 1–3 的含义与 GUID。
组件尺寸以栅栏图标格为单位（见 [组件网格](WIDGET_GRID.md)）：便笺与待办默认 5×4 格（默认设置下 400×384 DIP），调整大小时按整格吸附；使用 16 DIP 内容边距，沿用相邻放置、碰撞避让和 DPI 恢复。
便笺、待办和日历共用页眉：标题下方是一行摘要（便笺字数/行数、待办进度、日历今天或已选日期），右侧为胶囊或图标操作。按钮文字、勾选框和日期通过插件文本的 `TextAlign` 居中绘制。面板较窄或文字缩放较大时，文字按钮收起为 Segoe Fluent Icons 图标并保留无障碍名称。

- 便笺：正文卡片占满页眉以下区域；“撤销上一步”为页眉图标按钮；空便笺显示居中提示及 Ctrl+Enter/Esc 说明。
- 待办：页眉下方为完成进度条；未完成项在前、已完成项在后且不显示卡片底色，操作仍按存储序号执行；页脚为“清除已完成”、撤销图标和分页。
- 日历：固定六周网格，相邻月份日期以弱化颜色显示且不可点击；今天为实心强调色圆形，已选日期为强调色浅底。
- 中文界面的日历在日期下显示农历日（初一显示月名）、二十四节气（2001–2099 年，按 21 世纪公式及已知修正）和常见节日；页眉摘要附带农历。农历换算使用 `chinese-lunisolar-calendar`（1901–2100）。
- 便笺可切换纸张颜色（默认、黄、绿、粉、紫、蓝、灰），保存为可选的 `tint` 字段；默认颜色不写入该字段，原有配置格式不变。高对比度下忽略纸张颜色。
- 高度低于 120 DIP 时三种组件绘制单行胶囊摘要：便笺首行、下一项待办、今天及农历。

## 配色与字体

便笺、待办和日历采用暖纸色方案：组件自绘纸色底（#F6F1E7），卡片 #ECE4D6，正文墨色 #2B2722，次要文字 #685F55，强调色赤陶 #A9502D（文字用 #944526，赤陶底上用奶白 #FFF8EE）。正文、次要文字和强调文字组合经测试达到 WCAG 4.5:1（相邻月份等弱化信息使用独立颜色）。标题使用思源宋体 Noto Serif SC SemiBold，正文使用 Noto Sans SC（`FontRole::PaperBody`；应用其他部分仍为 Segoe UI Variable）。两者为 OFL 子集字体（拉丁字符、GB2312 符号与 3,755 个一级汉字），随包放在 EXE 旁的 `fonts/` 目录，由 DirectWrite 私有字体集合加载，不安装到系统。缺少该目录时回退到 Sitka Subheading 与 Segoe UI Variable；子集外的字符由 DirectWrite 回退到系统中文字体。时钟也使用相同的纸色方案，数字字体可在组件菜单中选择；高对比度模式下忽略纸色和便笺颜色，使用系统颜色。

## 纸张外观偏好

在设置 → 小组件外观中选择“小组件纸张”，或通过任一纸张组件的右键菜单切换（对所有纸张组件生效）：

- 跟随壁纸（默认）：按组件所在显示器的壁纸亮度选择暖深色、柔和或浅色纸面。亮度取自原图，先于玻璃模糊和主题染色；移动到其他显示器或更换壁纸后重新解析。
- 浅色纸张：保留原有暖白纸面。
- 柔和纸张：降低浅色纸面的明度。
- 深色纸张：使用暖炭色纸面与浅色文字。

“纸张亮度”可在 60%–100% 之间调整。固定纸色不随壁纸切换，偏好保存到工作区。时钟、日历、便笺、待办、图表及原生输入框共用此设置，彩色便笺也随纸面调色。正文、次要文字和强调文字根据最终纸面重新选择对比度；高对比度模式始终使用系统颜色。切换外观会先提交正在编辑的文本，再关闭旧配色的输入框。

## 中国节假日与调休

日历在年度安排中的休息日显示“休”，补班日显示“班”。点击日期可查看节假日名称与状态；窄格子以小圆点标记，完整说明仍在日期摘要与无障碍名称中。农历、节气和传统节日继续显示，传统节日不自动视为法定假日。

随包提供 2025、2026 年离线数据，来源为 MIT 许可的 `NateScarlet/holiday-cn`，依据其引用的国务院年度通知。数据与许可证见 `third_party/holiday-cn/`。应用在后台每天检查前一年、当前年和下一年，优先 GitHub 原始文件，失败时尝试 jsDelivr；成功校验后写入工作区目录旁的 `holiday-cache/<year>.json`。失败或断网时保留已验证缓存和内置数据，不阻塞绘制或退出。

右键“中国节假日”菜单显示所查看年份的数据状态、检查日期和官方通知入口。没有有效年度数据时显示“暂无…年放假安排”，不按农历猜测调休。当前为中国大陆公共安排，不含公司自定义工作日和通用 ICS 订阅。

## 时钟样式

时钟为纸色组件：大号数字按所占格数缩放，下方一段赤陶色短线和日期（中文显示农历与节日）；一行高时为胶囊，时间与日期并排。右键菜单（组件通过 `PanelInstance::menu_items` 提供选项）可选：

- 表盘样式：经典衬线（随包 Noto Serif SC）、现代（Segoe UI Variable Display）、数字窄体（Bahnschrift 窄体宽度，数字更高）。
- 字重：细 / 常规 / 中粗 / 粗（仅系统可变字体的“现代”和“数字窄体”可选；随包衬线只有一种字重）。
- 动态字重：参考 Android 锁屏时钟（AOSP SystemUI `AnimatableClockView` 动画化可变字体的 wght 轴）：每次时间变化，数字从相差 300 的字重回到所选字重（约 667 ms，逐级经过字体的命名字重）；“动画效果”关闭时不播放。
- 显示秒、12 小时制（上午/下午 移到日期行）。日历菜单另有“一周从周日开始”。

DirectWrite 将 Bahnschrift 的宽度作为同一家族的 stretch，而不是 GDI 的“Bahnschrift Condensed”家族名，因此窄体通过平台层的原始 DirectWrite 格式（`system_condensed_format`）绘制；失败时回退为正常宽度。菜单文字目前提供中文和英文。

## 动效

动效时长与曲线来自宿主共用的 Fluent 令牌（83/167/250/333 ms）。插件仅在补间进行时以 16 ms 唤醒绘制，结束后恢复原有唤醒节奏；Windows“动画效果”关闭时不创建补间，直接绘制结束状态。宿主在面板因输入请求重绘后重新读取其唤醒间隔。

- 待办：完成或恢复时各行从原位置滑到新位置（250 ms），勾选框中途放大 25%，卡片底色淡出或淡入；进度条缓动到新比例；新任务上移 8 DIP 并淡入。
- 日历：换月时日期由 15% 不透明度淡入，标题沿切换方向滑入 16 DIP（167 ms）；日期的点击区域不随动画移动。
- 便笺：纸张颜色 167 ms 交叉淡化；提交修改后页眉以强调色显示“✓ 已更新”约 1.2 s 后淡回摘要。
创建后立即打开对应输入框，取消输入保留空面板。单个组件的窗口没有标题栏（见 [组件网格](WIDGET_GRID.md) 的 Frameless widgets）：拖动组件上非控件区域移动，右键或 Shift+F10 打开栅栏菜单进行重命名、锁定或删除，边缘缩放；组件不能卷起。合并为多标签组时恢复标题栏。

## 便笺编辑

点击“编辑”或正文打开原生多行 EDIT 控件；光标置于末尾，支持原生文本选择、剪贴板、滚动和编辑撤销。
Enter 换行；Ctrl+Enter 提交；失去焦点提交；Esc 取消本次修改。提交后宿主按现有异步流程保存，不代表每次按键已写入磁盘。
读取时保留完整正文并在面板内裁剪；长文可进入可滚动编辑框查看。支持清空正文，提交后“撤销上一步”可恢复前一版，重启后撤销记录不保留。
仅纯文本，最多 8192 个 UTF-16 单位；保存为 LF 换行，进入 Windows 编辑框时转换为 CRLF。保留首尾空白，不允许 NUL。
当前不包含富文本、图片、云同步、便笺搜索或逐键保存，也不宣称与 Sticky Notes 功能对等。

## 输入框样式

输入框颜色在公共 `input_field` 边界成对解析。`Colors::input_surface` 提供编辑区底色；`input_palette` 将透明颜色合成到纸面，并对最终背景校正文字对比度。普通模式保留 RGB 取整余量；高对比度模式使用系统文字和表面颜色。组件不得将固定浅色底与主题文字直接拼接。原生 EDIT 的可编辑、只读状态均由同一颜色处理入口返回文字色、背景色和画刷。

组件打开的原生输入框统一为“就地字段”（`TextInputStyle`，由组件按当前布局给出，宿主绘制）：

- 字段覆盖被编辑的元素，文字位置与组件渲染的文字完全一致（字段 = 外框，`padding` 把文字放回原处）；单行文字垂直居中。
- 字段自绘底色与圆角，底部 2 DIP 强调色下划线表示正在编辑（Fluent 文本框聚焦样式；高对比度用系统前景色）。
- 字体与组件一致：随包附带的 Noto Sans SC / Noto Serif SC 以 `FR_PRIVATE` 方式只为本进程注册给 GDI（不安装到系统），缺失时回退到 Segoe UI Variable / Sitka；Mermaid 源码使用等宽 Consolas。
- 便笺：字段为整张纸卡片，使用当前纸张颜色。
- 待办编辑：字段从勾选框右侧开始，随纸色解析的“纸页”底，文字落在标题位置，勾选框保持可见。
- 待办添加：字段为当前页下一空行（满页时为第一行），显示“新任务…”占位提示。
- 图表：字段覆盖整个舞台，随纸色解析的纸页底、等宽字体、四周 14/12 DIP 内边距。



provider 为 `pecofence.note`，配置版本 1，格式为 `{ "text": "..." }`；默认空配置可创建空便笺。
正文与布局共存于工作区配置，通过 `PersistConfig` 更新同实例的布局副本。序列化/校验成功后再替换内存和撤销快照；宿主继续处理保存错误、备份和正常退出。
待办保留既有 `pecofence.todo` 配置和任务序号，不需要迁移。共用的输入请求增加明确的单/多行模式，单行编辑的 Enter/Esc 规则保持原语义。
便笺不依赖 SPM、网络或独立 daemon。面板中的文本属于用户数据，不作为指令解释。

## 验证

- 便笺配置与多行换行/Unicode/长度边界测试。
- 原生隐藏 EDIT 控件测试：多行 Enter 插入换行，单行 Enter 不插入。
- Shell action 既有编号与新编号往返；Windows COM 子菜单枚举与 GUID 顺序。
- `scripts/test-todo-widget.ps1`：隔离工作区的待办操作、多行便笺提交/撤销、打开并取消原生编辑框、重启后的正文和几何恢复。
- 自动化不替代真实鼠标、IME、屏幕阅读器和多显示器视觉验收。
