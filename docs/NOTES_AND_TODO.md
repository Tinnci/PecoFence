# 便笺与待办的统一组件体验

本轮基于现有原生组件实现，参考 Microsoft Sticky Notes 的快速记录方式：
https://support.microsoft.com/en-us/windows/apps/stickynotes/create-a-sticky-note

## 创建与呈现

托盘和面板右键的“新建小组件”复用同一个菜单：便笺、待办清单、数字时钟、日历。
MSIX 的 Windows Explorer 文件夹背景菜单扩展并列提供“新建便笺”和“新建待办清单”；普通 ZIP 安装不自动注册该扩展。新增 Shell action 使用 ID 4，保留已有 1–3 的含义与 GUID。
便笺与待办使用相同的 420×370 DIP 初始尺寸、主题颜色和 16 DIP 内容边距；沿用相邻放置、碰撞避让和 DPI 恢复。
便笺、待办和日历共用页眉：标题下方是一行摘要（便笺字数/行数、待办进度、日历今天或已选日期），右侧为胶囊或图标操作。按钮文字、勾选框和日期通过插件文本的 `TextAlign` 居中绘制。面板较窄或文字缩放较大时，文字按钮收起为 Segoe Fluent Icons 图标并保留无障碍名称。

- 便笺：正文卡片占满页眉以下区域；“撤销上一步”为页眉图标按钮；空便笺显示居中提示及 Ctrl+Enter/Esc 说明。
- 待办：页眉下方为完成进度条；未完成项在前、已完成项在后且不显示卡片底色，操作仍按存储序号执行；页脚为“清除已完成”、撤销图标和分页。
- 日历：固定六周网格，相邻月份日期以弱化颜色显示且不可点击；今天为实心强调色圆形，已选日期为强调色浅底。
创建后立即打开对应输入框，取消输入保留空面板。通过外框重命名、移动、缩放或删除组件，便笺组件不另设不同的窗口管理方式。

## 便笺编辑

点击“编辑”或正文打开原生多行 EDIT 控件；光标置于末尾，支持原生文本选择、剪贴板、滚动和编辑撤销。
Enter 换行；Ctrl+Enter 提交；失去焦点提交；Esc 取消本次修改。提交后宿主按现有异步流程保存，不代表每次按键已写入磁盘。
读取时保留完整正文并在面板内裁剪；长文可进入可滚动编辑框查看。支持清空正文，提交后“撤销上一步”可恢复前一版，重启后撤销记录不保留。
仅纯文本，最多 8192 个 UTF-16 单位；保存为 LF 换行，进入 Windows 编辑框时转换为 CRLF。保留首尾空白，不允许 NUL。
当前不包含富文本、图片、云同步、便笺搜索或逐键保存，也不宣称与 Sticky Notes 功能对等。

## 保存与边界

provider 为 `pecofence.note`，配置版本 1，格式为 `{ "text": "..." }`；默认空配置可创建空便笺。
正文与布局共存于工作区配置，通过 `PersistConfig` 更新同实例的布局副本。序列化/校验成功后再替换内存和撤销快照；宿主继续处理保存错误、备份和正常退出。
待办保留既有 `pecofence.todo` 配置和任务序号，不需要迁移。共用的输入请求增加明确的单/多行模式，单行编辑的 Enter/Esc 规则保持原语义。
便笺不依赖 SPM、网络或独立 daemon。面板中的文本属于用户数据，不作为指令解释。

## 验证

- 便笺配置与多行换行/Unicode/长度边界测试。
- 原生隐藏 EDIT 控件测试：多行 Enter 插入换行，单行 Enter 不插入。
- Shell action 既有编号与新编号往返；Windows COM 子菜单枚举与 GUID 顺序。
- `scripts/test-todo-widget.ps1`：隔离工作区的待办操作、多行便笺提交/撤销、打开并取消原生编辑框、重启后的正文和几何恢复。
- 自动化不替代真实鼠标、IME、屏幕阅读器和多显示器视觉验收。
